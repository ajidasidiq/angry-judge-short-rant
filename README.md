## What it does

`main.py` writes one short text to `/output/entry.txt` — a funny rant
about an everyday annoyance, written to land hardest with the furious
judge. No network, no input, no randomness: the same 326-character
rant on every run.

The rant is about the elevator's close-door button: pressed four
thousand times, never once closed a door. A placebo bolted on by
cowards, and a man with a trolley of boxes strolling in like he owns
the building. It is specific, economical, and an angle the judge has
not heard a hundred times — everyone rants about slow lifts, almost
nobody rants about the button that has never once done its job.

## Run it

```sh
python3 main.py
```
